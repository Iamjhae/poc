## Network Architecture Discovery

### Finding: Envoy Sidecar Proxy Deployment

The target 13.13.1.112 sits behind an **Envoy proxy** sidecar. HTTP requests to port 80 return responses from Envoy when the upstream (Xerox printer web server) is unavailable:

```
HTTP/1.1 503 Service Unavailable
Connection: close
Content-Length: 95
Content-Type: text/plain
Date: Sun, 27 Sep 2026 22:48:36 GMT
Server: envoy
X-Sidecar-Response-Code-Details: upstream_reset_before_response_started{connection_termination}
X-Sidecar-Response-Flags: UC

upstream connect error or disconnect/reset before headers. reset reason: connection termination
```

**Security observations from Envoy response:**
1. `Server: envoy` - Proxy technology disclosure
2. `X-Sidecar-Response-Code-Details` - Internal proxy behavior disclosure (reveals connection termination details)
3. `X-Sidecar-Response-Flags: UC` - Internal flag disclosure (UC = UpstreamConnectionTermination)
4. The sidecar architecture itself reveals deployment topology
