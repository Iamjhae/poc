## CVEs Applicable to Xerox VersaLink C625

### CVE-2024-6333 — Authenticated Remote Code Execution (CRITICAL)

| Field | Value |
|-------|-------|
| **CVSS** | 7.2 (HIGH) |
| **Type** | CWE-77: Command Injection |
| **Requires Auth** | Yes (admin access) |
| **Affected** | VersaLink B625/C625 explicitly listed in XRX24-015 |
| **Fixed In** | Firmware 121.xxx.004.22720 |
| **Discoverer** | Timo Longin & Tamas Jos (SEC Consult) |

**Description:** Authenticated RCE via command injection in the "Network Troubleshooting" menu. The tcpdump tool's IPv4 address field has insufficient input validation, allowing injection of arbitrary OS commands that execute as root.

**Attack Path:**
1. Authenticate as admin (default creds: admin/1111)
2. Navigate to Network Troubleshooting
3. Inject command in IPv4 address field: `;id;` or `$(whoami)`
4. Commands execute as root on the underlying OS

**Relevance to Our Findings:**
- If default credentials work (Test 3), this gives direct RCE
- Combined with Finding 2 (CSRF) and Finding 9 (unauthenticated admin functions), an attacker chain exists:
  1. Extract CSRF token from unauthenticated page
  2. Use admin:1111 default credentials to authenticate
  3. Access Network Troubleshooting page
  4. Execute arbitrary commands as root

**Source:** [Xerox Security Bulletin XRX24-015](https://security.business.xerox.com/xerox-security-bulletin-xrx24-015-for-altalink-versalink-and-workcentre-cve-2024-6333/) | [SEC Consult Advisory](https://sec-consult.com/vulnerability-lab/advisory/authenticated-remote-code-execution-in-multiple-xerox-printers/)

### CVE-2024-12510 — LDAP Pass-Back Attack (HIGH)

| Field | Value |
|-------|-------|
| **CVSS** | 6.7 (MEDIUM) |
| **Type** | Credential Theft via LDAP Redirect |
| **Requires Auth** | Yes (admin access to LDAP config) |
| **Affected** | VersaLink family (C7020/C7025/C7030 confirmed; C625 same codebase) |
| **Fixed In** | Service Pack 57.75.53 (C7025 series) |
| **Discoverer** | Rapid7 |

**Description:** An attacker with admin access can change the LDAP server address to an attacker-controlled server. When the printer authenticates against LDAP, credentials are sent in cleartext to the malicious server, enabling credential capture.

**Relevance to Our Findings:**
- Finding 9 shows `HTTP_Set_LDAP_fn` is accessible via unauthenticated POST to `/dummypost/xerox.set`
- If the LDAP server address can be changed without authentication (using the exposed CSRF token), this becomes a **pre-auth credential theft** vulnerability
- The focused_retest.sh (Test A) targets this exact scenario
- **Our Finding 9 may represent an escalated variant of CVE-2024-12510** — the CVE requires admin access, but if xerox.set processes the LDAP change without auth, it's a new finding

**Source:** [Rapid7 Blog](https://www.rapid7.com/blog/post/2025/02/14/xerox-versalink-c7025-multifunction-printer-pass-back-attack-vulnerabilities-fixed/) | [The Hacker News](https://thehackernews.com/2025/02/new-xerox-printer-flaws-could-let.html)

### CVE-2024-12511 — SMB/FTP Pass-Back Attack (HIGH)

| Field | Value |
|-------|-------|
| **CVSS** | 7.6 (HIGH) |
| **Type** | Credential Theft via SMB/FTP Redirect |
| **Requires Auth** | Yes (address book access) |
| **Affected** | VersaLink family |
| **Fixed In** | Service Pack 57.75.53 (C7025 series) |
| **Discoverer** | Rapid7 |

**Description:** An attacker with access to the address book can modify SMB/FTP scan destinations. When a user scans a document, the printer sends the scan to the attacker-controlled server, along with SMB/NTLM authentication credentials.

**Relevance to Our Findings:**
- Finding 9 shows `HTTP_Set_FTP_fn` and `HTTP_Set_SMB_fn` are accessible via unauthenticated POST
- If these functions modify scan destinations without auth, this is a **pre-auth variant** of CVE-2024-12511
- Combined with `HTTP_Set_Email_fn`, scan-to-email could be redirected to attacker email

**Source:** [Rapid7 Blog](https://www.rapid7.com/blog/post/2025/02/14/xerox-versalink-c7025-multifunction-printer-pass-back-attack-vulnerabilities-fixed/) | [SecurityWeek](https://www.securityweek.com/xerox-versalink-printer-vulnerabilities-enable-lateral-movement/)

### CVE-2022-23968 — TIFF Parsing Permanent DoS (Bricking)

| Field | Value |
|-------|-------|
| **CVSS** | 7.5 (HIGH) |
| **Type** | Improper Input Validation |
| **Requires Auth** | No |
| **Affected** | VersaLink devices on older firmware |
| **Fixed In** | Firmware updates post 2022-01-26 |

**Description:** A crafted TIFF file sent via unauthenticated HTTP POST causes the printer to enter an infinite reboot loop, permanently bricking the device until firmware reflash.

**Relevance:** The C625 print submission page (Finding 1) accepts file uploads without authentication. If the firmware is old enough, CVE-2022-23968 may still apply. However, the Web UI version 1.13.1 and the device's cert date (May 2026) suggest relatively recent firmware, likely patched.

**Source:** [NeoSmart](https://neosmart.net/blog/xerox-vulnerability-allows-unauthenticated-network-users-to-remotely-brick-printers/) | [SecurityWeek](https://www.securityweek.com/xerox-quietly-patched-device-bricking-flaw-some-printer-models/)

### CVE-2020-9330 — LDAP Credential Modification Without Reauth

| Field | Value |
|-------|-------|
| **CVSS** | 8.8 (HIGH) |
| **Type** | Missing re-authentication for LDAP connector changes |
| **Requires Auth** | Yes (initial auth, but no re-auth for changes) |
| **Affected** | Xerox WorkCentre series (pre 073.xxx) |

**Description:** The LDAP connector IP address can be changed without re-entering bind credentials. An attacker with device access can redirect LDAP to a rogue server and capture credentials.

**Relevance:** Direct predecessor to CVE-2024-12510. Same attack class. Our Finding 9 may extend this to fully unauthenticated access.

## Attack Chain Analysis

### Chain 1: Unauthenticated Credential Theft (HIGH IMPACT)
```
Finding 5 (CSRF token exposed) + Finding 9 (HTTP_Set_LDAP_fn without auth)
→ Change LDAP server to attacker-controlled
→ Capture domain credentials when printer authenticates
→ Lateral movement into Active Directory
```
This is an **unauthenticated variant** of CVE-2024-12510 if confirmed.

### Chain 2: Default Creds → RCE (CRITICAL)
```
Default creds admin:1111 → CVE-2024-6333 (command injection in tcpdump)
→ Root shell on printer
→ Pivot into internal network
```

### Chain 3: PostScript → Filesystem Access (HIGH)
```
Finding 1 (unauth print submission) → PostScript file I/O
→ Read /etc/passwd, /etc/shadow, config files
→ Extract stored credentials, network config
→ Further compromise
```

### Chain 4: CSRF → Device Takeover (HIGH)
```
Finding 5 (CSRF token) + Finding 2 (reboot) + Finding 9 (20 admin functions)
→ Change all device settings without authentication
→ Redirect email/scan/fax to attacker
→ Upload malicious firmware
→ Factory reset (destructive)
```
